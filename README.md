# A.Game

게임의 알레고리와 관습을 걷어내고 **개념만으로 이루어진 게임**을 만드는 개념 게임 프로젝트입니다.
숫자, 문자, 게이지 같은 게임 UI가 없습니다. 의미 있는 색도 없습니다. 최소한의 도형만으로 이용자가 이 게임을 이해하고 학습할 수 있는지를 묻습니다.

## 도형의 의미

| 도형 | 의미 | 나타나는 곳 |
|---|---|---|
| △ 삼각형 | 공격 그 자체 | 무기, 공격 궤적, 적의 공격 예고 |
| ○ 원 | 체력 그 자체 | 상단 체력 (원 1개 = 체력 1, 잃으면 떨어져 나감), 맞으면 피해량만큼 흘러나와 사라지는 원, 적 아래의 작은 원 |
| □ 사각형 | 체력 체계에서 벗어남 | 가드, 막아낸 피해만큼 튀어나오는 사각형, 출구 |

- **몸**: 플레이어는 원, 적은 타원입니다. 앞으로 캐릭터마다 타원 비율이나 모서리 둥글기로 변형할 예정입니다.
- **색**: 흑백뿐입니다. 플레이어와 적은 형태와 명도로만 구분합니다.
- **표기 규칙**: 세계 안의 도형은 채워서 그리고, 조작 기호는 외곽선으로 그립니다. 조작 기호는 누르는 동안에만 채워집니다.
- **수치**: 모든 수치는 작은 정수입니다. 개수로 셀 수 있어야 하기 때문입니다.

## 무기: 삼각형의 형태와 궤적

| 무기 | 삼각형 | 궤적 | 피해 |
|---|---|---|---|
| 검 | 길고 가늘다 | 호를 그리는 3연타 (아래, 위, 내려찍기) | 1, 1, 2 |
| 창 | 아주 길고 뾰족하다 | 직선 찌르기 2연타, 사거리 김 | 2, 2 |
| 단검 | 작다 | 빠른 찌르기 3연타 | 1, 1, 1 |
| 망치 | 짧고 넓다 | 느린 내려찍기 1회 | 3 |

바닥에 놓인 삼각형 위에 서면 그 삼각형이 밝아지고 과녁 모양 버튼(원 두 개)이 나타납니다. 버튼을 누르면 들고 있던 무기와 바뀌고, 누르지 않고 지나가면 그대로 둡니다. 무기는 `src/weapons.ts`에 데이터로 정의되어 있어서, 새 무기는 형태와 궤적만 추가하면 됩니다.

## 가드

- 가드를 누르고 있으면 몸 앞에 사각형이 섭니다. 이동은 멈추고 방향만 바꿀 수 있습니다.
- 가드는 공격 하나에서 1만큼 막습니다. 막은 만큼은 사각형으로, 뚫린 만큼은 원으로 튀어나옵니다.
- **패링**: 공격이 닿기 직전에 가드를 올리면 전부 사각형으로 막고, 적이 잠시 무너집니다.
- 적은 공격하기 전에 삼각형을 키웁니다. 그것이 가드하거나 구를 신호입니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173 (같은 Wi-Fi의 휴대폰에서도 접속 가능)
npm run build      # 타입 체크 후 dist/에 배포용 빌드 생성
```

**휴대폰에서 테스트하기:** `npm run dev`를 실행하면 `Network:` 주소(예: `http://192.168.0.12:5173`)가 표시됩니다. 휴대폰 브라우저로 그 주소에 접속한 뒤 가로로 돌리면 됩니다.

URL 끝에 `?debug`를 붙이면 물리 판정 박스와 fps가 보이고, 콘솔에서 `window.game`을 쓸 수 있습니다.

## 조작

터치와 키보드를 모두 지원합니다. 키를 누르면 터치 기호가 사라지고, 화면을 터치하면 다시 나타납니다.

| 동작 | 터치 기호 | 키보드 |
|---|---|---|
| 이동 | 화면 왼쪽 절반 (누르면 가로선이 나타남) | ← → / A D |
| 공격 | △ | X / J |
| 가드 | □ | V / L / Shift |
| 점프 | 세로선 세 개 | Space / ↑ / W / Z |
| 구르기 (무적, 공격 캔슬) | 가로선 세 개 | C / K |
| 무기 줍기/교체 (무기 위에 있을 때만) | 원 두 개 (과녁) | E / F |

키 배치는 `src/config.ts`의 `KEY_BINDINGS`에서 바꿀 수 있습니다.

## 조작감 시스템

- **입력 버퍼링 (150ms)**: 조금 일찍 누른 입력도 실행됨
- **코요테 타임 (100ms)**: 발판에서 떨어진 직후에도 점프 가능
- **벽에 붙어서 점프**: 벽을 향해 이동하면서 점프해도 벽을 타고 미끄러지듯 정상 높이로 올라감
- **가변 점프**: 점프 버튼을 짧게 누르면 낮게 뜀
- **구르기 캔슬**: 공격 도중 언제든 구르기로 끊을 수 있음
- **히트스톱, 화면 흔들림, 넉백**
- **멀티터치**: 이동, 공격, 가드, 점프를 동시에 입력 가능

모든 수치는 `src/config.ts`에서 조정합니다.

## 구조

```
src/
  main.ts                 게임 설정 (휴대폰 화면비에 맞춰 가로 폭 자동 조정)
  config.ts               조작감 수치, 흑백 팔레트, 키 배치
  weapons.ts              무기 정의 (삼각형 형태와 궤적)
  effects.ts              원 출혈, 사각형 가드, 삼각형 잔상
  level.ts                텍스트 기반 맵 데이터, 충돌체
  input/InputState.ts       기기 독립 입력 상태 (버퍼링)
  input/TouchControls.ts    플로팅 조이스틱, 버튼, 멀티터치
  input/KeyboardControls.ts 키보드 입력 (마지막 방향 우선)
  objects/Player.ts       플레이어 상태 머신 (이동/점프/공격/가드/구르기/피격)
  objects/Enemy.ts        적 AI (순찰, 추적, 삼각형 예고, 돌진)
  objects/WeaponPickup.ts 바닥에 놓인 무기
  scenes/BootScene.ts     도형 텍스처 생성
  scenes/GameScene.ts     월드, 전투, 히트스톱, 카메라
  scenes/UIScene.ts       HUD, 입력 모드 전환
```

## 배포

`.github/workflows/deploy.yml`이 `main` 브랜치에 push될 때마다 GitHub Pages로 배포합니다.
처음 배포하기 전에 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔 주세요.
`github-pages` 환경의 배포 허용 브랜치에 `main`이 있어야 합니다 (**Settings → Environments → github-pages**).
