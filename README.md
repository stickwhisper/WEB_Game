# A.Game

게임의 알레고리와 관습을 걷어내고 **개념만으로 이루어진 게임**을 만드는 개념 게임 프로젝트입니다.
숫자, 문자, 게이지 같은 게임 UI가 없습니다. 의미 있는 색도 없습니다. 최소한의 도형만으로 이용자가 이 게임을 이해하고 학습할 수 있는지를 묻습니다.

## 도형의 의미

| 도형 | 의미 | 나타나는 곳 |
|---|---|---|
| △ 삼각형 | 공격 그 자체 | 무기, 공격 궤적, 적의 공격 예고 |
| ○ 원 | 체력 그 자체 | 상단 체력 (원 1개 = 체력 1, 잃으면 떨어져 나감), 맞으면 피해량만큼 흘러나와 사라지는 원, 적 아래의 작은 원, 적이 남긴 회복 원 |
| □ 사각형 | 체력 체계에서 벗어남 | 가드, 막아낸 피해만큼 튀어나오는 사각형, 수호형 적의 정면 방패, 보스의 판, 방의 출구, 지나온 출구 수 |

- **몸**: 플레이어는 원, 적은 타원입니다. 앞으로 캐릭터마다 타원 비율이나 모서리 둥글기로 변형할 예정입니다.
- **색**: 흑백뿐입니다. 플레이어와 적은 형태와 명도로만 구분합니다.
- **표기 규칙**: 세계 안의 도형은 채워서 그리고, 조작 기호는 외곽선으로 그립니다. 조작 기호는 누르는 동안에만 채워집니다.
- **수치**: 모든 수치는 작은 정수입니다. 개수로 셀 수 있어야 하기 때문입니다.
- **소리**: 사인파만 씁니다. 도형마다 음높이가 하나씩 있습니다(삼각형 784Hz, 원 392Hz, 사각형 587Hz). 원 3개를 잃으면 소리도 3번 나서 귀로도 셀 수 있습니다. 회복은 원의 음이 올라가고, 출구가 열리면 사각형 음이 길게 납니다.

## 무기: 삼각형의 형태와 궤적

| 무기 | 삼각형 | 궤적 | 피해 |
|---|---|---|---|
| 검 | 길고 가늘다 | 호를 그리는 3연타 (아래, 위, 내려찍기) | 1, 1, 2 |
| 창 | 아주 길고 뾰족하다 | 직선 찌르기 2연타, 사거리 김 | 2, 2 |
| 단검 | 작다 | 빠른 찌르기 3연타 | 1, 1, 1 |
| 망치 | 짧고 넓다 | 느린 내려찍기 1회 | 3 |

바닥에 놓인 삼각형 위에 서면 그 삼각형이 밝아지고, 위에 공격력이 삼각형 개수로 뜨고, 과녁 모양 버튼(원 두 개)이 나타납니다. 버튼을 누르면 들고 있던 무기와 바뀌고, 누르지 않고 지나가면 그대로 둡니다. 무기는 `src/weapons.ts`에 데이터로 정의되어 있어서, 새 무기는 형태와 궤적만 추가하면 됩니다.

## 방과 첫 스테이지

게임은 방 단위로 이어집니다. 방의 사각형 출구는 흐리게 닫혀 있다가, 방 안의 적이 모두 사라지면 밝아지며 열립니다. 체력과 들고 있는 무기는 다음 방으로 이어지고, 죽으면 처음 방부터 다시 시작합니다.

첫 스테이지의 7개 방은 글자 없이 배치만으로 하나씩 가르칩니다.

| 방 | 가르치는 것 | 구성 |
|---|---|---|
| 1 | 이동, 점프 | 적 없음. 턱, 얕은 구덩이, 한 번에 뛰어야 넘는 벽 |
| 2 | △ 공격 | 반격하지 않는 적 하나. 때리면 원이 흐름 |
| 3 | 삼각형 예고 | 돌진형 하나와 물러설 공간 |
| 4 | □ 가드 | 천장이 낮아 뛰어넘을 수 없는 통로 속 돌진형 |
| 5 | ○ 회복 | 원을 남기는 도약형 셋 |
| 6 | 무기 교체 | 수호형 앞에 놓인 망치 (검은 정면 사각형에 막힘) |
| 7 | 출구 □ | 처음부터 보이는 출구, 그 앞의 거대형 |

## 한 판 (로그라이트 구조)

- 첫 스테이지는 이 기기에서 한 번 끝까지 통과하면 다음부터 건너뜁니다. 다시 보려면 주소 끝에 `?fresh`를 붙이세요.
- 그 뒤로는 매 판 방 8개 중 5개를 무작위로 뽑고, 각 방은 절반 확률로 좌우가 뒤집힙니다. 마지막은 보스 방입니다. 보스 방을 나가면 한 판이 끝나고 새 판이 시작됩니다.
- `R` 자리에는 들고 있지 않은 무기나 방패가 무작위로 놓이기도 합니다 (65%).
- 지나온 출구 수만큼 체력 원 아래에 작은 사각형이 쌓입니다. 죽으면 사각형 줄이 떨어져 나가고 새 판이 시작됩니다.

방 구성은 `src/rooms.ts`에 텍스트 격자로 있습니다.

## 적: 형태가 곧 성격

| 형태 | 적 | 체력 | 성격 | 남기는 원 |
|---|---|---|---|---|
| 가로 타원 | 돌진형 | 6 | 삼각형을 키운 뒤 돌진, 피해 2 | 1 |
| 세로로 긴 타원 | 도약형 | 3 | 빠름, 플레이어가 있는 곳을 향해 뛰어올라 내리꽂음, 피해 1 | 1 |
| 둥근 사각형 | 수호형 | 8 | 정면을 사각형으로 막음(2까지). 등 뒤나 공격 중일 때 노려야 함, 피해 2 | 2 |
| 크고 납작한 타원 | 거대형 | 12 | 느리고 맞아도 흔들리지 않음. 큰 삼각형을 휘둘러 피해 3 (가드로는 1만 막힘) | 3 |

수치는 `src/enemies.ts`에 정의되어 있습니다.

### 보스: 결합된 도형

매 판의 마지막 방에는 거대한 타원이 정면에 사각형 판 4개를 두르고 있습니다.

- 정면으로 때리면 먼저 사각형 판이 깨집니다. 판 하나가 2만큼 막은 뒤 떨어져 나갑니다. 판이 모두 떨어진 뒤에야 원이 흐릅니다. 등 뒤를 치면 판을 거치지 않습니다.
- 공격은 3가지입니다. 가까우면 큰 삼각형 휘두르기(피해 3), 중간 거리면 돌진(2), 멀면 플레이어를 겨냥한 도약(2)입니다.
- 원이 절반(12) 이하로 줄면 삼각형을 키우는 시간이 짧아집니다.
- 맞아도 흔들리지 않고, 패링해야만 무너집니다. 체력 24, 남기는 원 5개

## 원의 순환

적이 죽으면 그 몸에서 원이 튀어나와 바닥에 남습니다. 체력이 줄어 있을 때 그 위를 지나가면 원을 하나씩 되찾고, 상단 체력에 원이 다시 자라납니다. 체력이 가득 차 있으면 원은 바닥에 그대로 남아 기다립니다.

## 방패: 크기가 다른 사각형

방패도 무기처럼 바닥에 놓여 있고, 그 위에서 줍기(◎)로 바꿉니다. 사각형의 크기로 구분합니다. 처음에는 중간 방패를 듭니다.

| | 작은 방패 | 중간 방패 | 대형 방패 |
|---|---|---|---|
| 피해 감소 | 없음 (패링만) | 1 (드는 동안 최대 0.9초) | 2 (누르는 동안 계속) |
| 패링 | 드는 짧은 순간 전체 | 들어 올린 직후 | 불가 |
| 사용 | 누를 때마다 잠깐 듦, 연타 가능 | 누르고 있는 동안, 내린 뒤 잠시 대기 | 누르고 있는 동안, 내린 뒤 더 긴 대기 |
| 들고 이동 | 그대로 | 느리게 | 불가 (방향만 바꿈) |
| 그 외 | | | 평소 이동속도 감소. 들지 않을 때 등 뒤 공격을 상시 2만큼 막음 |

- 막은 만큼은 사각형으로, 뚫린 만큼은 원으로 튀어나옵니다.
- **패링**: 전부 사각형으로 막고 적이 잠시 무너집니다.
- 적은 공격하기 전에 삼각형을 키웁니다. 그것이 방패를 들거나 구를 신호입니다.
- 수치는 `src/shields.ts`에 있습니다.

## 무기와 방패의 성능 표시

바닥의 무기나 방패 위에 서면 그 위에 성능이 도형 개수로 떠오릅니다. 범위와 속도는 휘둘러 보면 바로 알 수 있지만, 공격력은 적이 없으면 알 수 없기 때문입니다.

- **무기**: 콤보 타격마다 삼각형 묶음. 검은 `▲ ▲ ▲▲`(1, 1, 2), 망치는 `▲▲▲`
- **방패**: 막는 양만큼 사각형. 대형은 `■■`, 작은 방패는 막지 않으므로 표시 없음
- 성장으로 얻은 공격력과 방패 성능이 반영된 값입니다.

## 학습 기록

게임 화면에는 아무것도 나타나지 않고, 기록만 합니다. "도형만으로 학습할 수 있는가"를 확인하기 위한 자료입니다.

- **처음 해낸 순간**: 이동, 점프, 공격, 적 명중, 가드, 막기, 패링, 구르기, 무기 줍기, 회복, 처치, 출구, 보스 방 통과(한 판 완주). 세션 시작부터 걸린 시간과 그때 있던 방을 남깁니다.
- **방마다**: 머문 시간, 잃은 체력, 막아낸 피해, 통과/사망, 사망 원인(적 종류 또는 추락)
- **저장 위치**: 기기 안(localStorage)에 최근 30개 세션까지 남습니다. 익명 무작위 기기 ID만 쓰고 개인 정보는 없습니다.
- **원격 전송**: 빌드할 때 `VITE_TELEMETRY_URL`을 지정하면 방을 나갈 때마다, 그리고 페이지를 닫을 때 그 주소로도 보냅니다. 지정하지 않으면 기기 밖으로 나가지 않습니다.
- **확인 방법**: `?debug`로 열고 브라우저 콘솔에서 `telemetry.data`(현재 세션) 또는 `telemetry.history()`(저장된 전체)를 봅니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173 (같은 Wi-Fi의 휴대폰에서도 접속 가능)
npm run build      # 타입 체크 후 dist/에 배포용 빌드 생성
```

**오프라인 실행:** 배포된 주소에 한 번 접속하면 게임 파일이 기기에 저장됩니다. 그 뒤로는 네트워크 없이도 실행되고, "홈 화면에 추가"하면 도형 아이콘으로 앱처럼 열립니다. 연결되어 있을 때는 항상 최신 버전을 먼저 받아옵니다(`public/sw.js`).

**휴대폰에서 테스트하기:** `npm run dev`를 실행하면 `Network:` 주소(예: `http://192.168.0.12:5173`)가 표시됩니다. 휴대폰 브라우저로 그 주소에 접속한 뒤 가로로 돌리면 됩니다.

URL 끝에 `?debug`를 붙이면 물리 판정 박스와 fps가 보이고, 콘솔에서 `window.game`을 쓸 수 있습니다.

## 조작

터치와 키보드를 모두 지원합니다. 키를 누르면 터치 기호가 사라지고, 화면을 터치하면 다시 나타납니다.

| 동작 | 터치 기호 | 키보드 |
|---|---|---|
| 이동 | 화면 왼쪽 절반 (누르면 가로선이 나타남) | ← → / A D |
| 공격 | △ | X / J |
| 가드 | □ | V / L / Shift |
| 점프 | 세로선 세 개 | Space / ↑ / W / Z |
| 구르기 (무적, 공격 캔슬) | 가로선 세 개 | C / K |
| 무기 줍기/교체 (무기 위에 있을 때만) | 원 두 개 (과녁) | E / F |

**키 설정:** 오른쪽 위 설정 아이콘(손잡이가 달린 선 두 개)이나 Esc로 설정 화면을 엽니다. 열려 있는 동안 게임은 멈춥니다. 설정 화면에도 글자가 없습니다.

- 왼쪽: 동작 기호 7개 (← → 이동, 점프, 공격, 가드, 구르기, 줍기)
- 오른쪽: 선으로 그린 키보드. 키 이름 없이 위치로 구분합니다.
- 기호를 고르면 그 동작의 키가 밝게 채워집니다. 다른 동작에 쓰인 키는 흐리게 채워집니다.
- 키를 누르거나 그림의 키를 누르면 그 동작에 추가됩니다. 같은 키를 다시 누르면 빠집니다. 다른 동작의 키를 누르면 그 키가 이쪽으로 옮겨옵니다.
- 동작마다 키가 최소 1개는 남습니다(마지막 키는 빠지지 않음).
- 원형 화살표는 기본값으로 되돌리고, ×나 Esc는 닫습니다.
- 설정은 이 기기에 저장됩니다. 기본값은 `src/config.ts`의 `KEY_BINDINGS`입니다.

**화면 비율 대응:** 4:3 태블릿부터 24:9 초광폭 휴대폰까지 빈 띠 없이 화면을 채웁니다(게임 폭 720~1440, 노치와 홈 바를 뺀 영역 기준). 화면이 작은 휴대폰에서는 버튼과 체력 원이 최대 1.4배 커져서, 실제 화면에서 공격 버튼 약 44px, 나머지 버튼 약 32px 이상을 유지합니다.

## 조작감 시스템

- **입력 버퍼링 (150ms)**: 조금 일찍 누른 입력도 실행됨
- **코요테 타임 (100ms)**: 발판에서 떨어진 직후에도 점프 가능
- **낙하**: 방 밖으로 떨어지면 원 1개를 잃고, 떨어지기 직전에 서 있던 안정적인 땅으로 돌아옵니다. 두 발 아래가 모두 실제 땅인 곳만 기억하며, 선 발판과 땅 끝 가장자리는 제외합니다. 마지막 원이었다면 그대로 끝납니다.
- **벽에 붙어서 점프**: 벽을 향해 이동하면서 점프해도 벽을 타고 미끄러지듯 정상 높이로 올라감
- **가변 점프**: 점프 버튼을 짧게 누르면 낮게 뜀
- **구르기 캔슬**: 공격 도중 언제든 구르기로 끊을 수 있음
- **히트스톱, 화면 흔들림, 넉백**
- **멀티터치**: 이동, 공격, 가드, 점프를 동시에 입력 가능

모든 수치는 `src/config.ts`에서 조정합니다.

## 구조

```
src/
  main.ts                 게임 설정 (휴대폰 화면비에 맞춰 가로 폭 자동 조정)
  config.ts               조작감 수치, 흑백 팔레트, 키 배치
  weapons.ts              무기 정의 (삼각형 형태와 궤적)
  enemies.ts              적 정의 (몸의 형태, 체력, 공격, 가드, 남기는 원, 보스의 판과 추가 공격)
  effects.ts              원 출혈, 사각형 가드, 삼각형 잔상
  tones.ts                도형별 사인파 소리
  level.ts                방 격자 해석, 충돌체
  rooms.ts                방 정의 (첫 스테이지 7개, 무작위 방 8개, 보스 방)
  run.ts                  한 판의 진행 (방 뽑기와 뒤집기, 이어지는 체력과 무기, 첫 스테이지 통과 기억)
  telemetry.ts            학습 기록 (처음 해낸 순간, 방별 결과)
  input/InputState.ts       기기 독립 입력 상태 (버퍼링)
```

## 배포

`.github/workflows/deploy.yml`이 `main` 브랜치에 push될 때마다 GitHub Pages로 배포합니다.
처음 배포하기 전에 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔 주세요.
`github-pages` 환경의 배포 허용 브랜치에 `main`이 있어야 합니다 (**Settings → Environments → github-pages**).
