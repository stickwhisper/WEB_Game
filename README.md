# Web Action Roguelite — 터치 프로토타입

데드셀 스타일의 2D 액션 웹게임 프로토타입입니다. **터치만으로 조작**할 수 있습니다(버튼형).
Phaser 3 + TypeScript + Vite로 만들었고, 그래픽은 모두 코드로 생성하기 때문에 아직 에셋 파일이 없습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173 (같은 Wi-Fi의 휴대폰에서도 접속 가능)
npm run build      # 타입 체크 후 dist/에 배포용 빌드 생성
```

**휴대폰에서 테스트하기:** `npm run dev`를 실행하면 `Network:` 주소(예: `http://192.168.0.12:5173`)가 표시됩니다. 휴대폰 브라우저로 그 주소에 접속한 뒤 가로로 돌리면 됩니다.

URL 끝에 `?debug`를 붙이면 물리 판정 박스가 보이고, 콘솔에서 `window.game`을 쓸 수 있습니다.

## 조작

터치와 키보드 모두 지원합니다. 두 입력은 항상 같이 동작하고, 화면 UI만 바뀝니다.

- **자동 전환**: 키를 누르면 키보드 모드가 되어 터치 버튼이 사라지고 화면 아래에 키 안내가 나옵니다. 화면을 터치하면 터치 모드로 돌아옵니다.
- **수동 전환**: 오른쪽 위 `입력: 터치 / 키보드` 버튼을 누르면 바뀝니다.
- **시작 모드**: 터치 기기는 터치 모드, PC는 키보드 모드로 시작합니다.

| 동작 | 터치 | 키보드 |
|---|---|---|
| 이동 | 화면 왼쪽 절반: 플로팅 조이스틱 | ← → / A D |
| 점프 (길게 누르면 더 높이) | 점프 버튼 | Space / ↑ / W / Z |
| 공격 (3단 콤보) | 공격 버튼 | X / J |
| 구르기 (무적, 공격 캔슬) | 구르기 버튼 | C / K / Shift |

키보드는 마지막에 누른 방향이 우선합니다. →를 누른 채 ←를 누르면 바로 방향이 바뀝니다.
키 배치는 `src/config.ts`의 `KEY_BINDINGS`에서 바꿀 수 있습니다.

적은 돌진하기 직전에 빨갛게 깜빡입니다. 그때 구르기로 피하세요.

## 조작감 시스템

- **입력 버퍼링 (150ms)**: 조금 일찍 누른 입력도 실행됨
- **코요테 타임 (100ms)**: 발판에서 떨어진 직후에도 점프 가능
- **가변 점프**: 점프 버튼을 짧게 누르면 낮게 뜀
- **구르기 캔슬**: 공격 도중 언제든 구르기로 끊을 수 있음
- **히트스톱, 화면 흔들림, 넉백**
- **멀티터치**: 이동, 공격, 점프를 동시에 입력 가능

모든 수치는 `src/config.ts`에서 조정합니다.

## 구조

```
src/
  main.ts                 게임 설정 (휴대폰 화면비에 맞춰 가로 폭 자동 조정)
  config.ts               조작감 수치, 콤보 정의
  level.ts                텍스트 기반 맵 데이터, 충돌체
  input/InputState.ts       기기 독립 입력 상태 (버퍼링)
  input/TouchControls.ts    플로팅 조이스틱, 버튼, 멀티터치
  input/KeyboardControls.ts 키보드 입력 (마지막 방향 우선)
  objects/Player.ts       플레이어 상태 머신 (이동/점프/공격/구르기/피격)
  objects/Enemy.ts        적 AI (순찰, 추적, 예고 동작, 돌진)
  scenes/BootScene.ts     임시 텍스처 생성
  scenes/GameScene.ts     월드, 전투, 히트스톱, 카메라
  scenes/UIScene.ts       HUD, 입력 모드 전환
```
